## 1. OVERVIEW & TUJUAN

### Latar Belakang
Pricing page KyloDev saat ini menampilkan paket secara flat tanpa diferensiasi add-on per paket, tidak ada maintenance yang terintegrasi per card, dan struktur HRIS belum mencakup modul lembur. Halaman perlu dirombak total untuk meningkatkan konversi, kejelasan value proposition, dan kemudahan user dalam memilih paket yang sesuai.

### Tujuan Utama
- Meningkatkan konversi dari pricing page ke WhatsApp/konsultasi
- Memperjelas value setiap paket vs harga yang dibayar
- Mengintegrasikan add-on langsung di setiap card (bukan halaman terpisah)
- Memudahkan user membandingkan paket secara visual

### Success Metrics
- Klik tombol "Pilih Paket" / "Konsultasi Gratis" meningkat
- Bounce rate pricing page menurun
- Lead yang masuk lebih qualified (sudah tahu paket apa yang mereka mau)

---

## 2. USER STORIES

**Sebagai pemilik UMKM**, saya ingin tahu dengan jelas apa yang saya dapat dengan budget yang saya punya, tanpa harus tanya-tanya dulu.

**Sebagai mahasiswa/freelancer**, saya ingin tahu apakah ada opsi yang sesuai budget terbatas saya, dan apa yang bisa ditambah nanti.

**Sebagai founder startup**, saya ingin bisa compare paket mobile app secara jelas untuk tahu mana yang cocok untuk MVP saya.

**Sebagai HRD/Manajer Perusahaan**, saya ingin tahu modul apa saja yang tersedia di HRIS sebelum saya minta demo.

**Sebagai returning visitor**, saya ingin tahu add-on apa yang bisa saya tambahkan ke paket yang sudah saya ambil.

## 5. UI/UX SPECIFICATION

### 5.1 Layout Desktop (≥1024px)

#### Navigation Tab
```
┌────────────────────────────────────────────────────┐
│  [Web Solution]  [Mobile App]  [Enterprise]        │
│       ↑ active tab = underline + color accent      │
└────────────────────────────────────────────────────┘
```
- Tab sticky saat scroll (position: sticky, top: 80px)
- Smooth scroll/fade transition antar tab (200ms ease)
- Active tab: warna lime accent + bold weight
- Inactive tab: muted color, regular weight

#### Grid Layout per Tab

**Web Solution → 3 kolom**
```
┌──────────┐  ┌──────────┐  ┌──────────┐
│ Starter  │  │ Business │  │E-Commerce│
│          │  │ ★ Populer│  │          │

│          │  │  shadow) │  │          │
└──────────┘  └──────────┘  └──────────┘
```
- Kolom tengah (Business) slightly elevated: scale(1.02), shadow lebih kuat, border accent
- Gap antar card: 24px
- Max width container: 1200px, centered

**Mobile App → 2 kolom centered**
```
          ┌──────────┐  ┌──────────┐
          │  Starter │  │ Business │
          │ ★ Populer│  │          │
          └──────────┘  └──────────┘
```
- Center aligned, max width 800px
- App Starter sebagai "Paling Populer"

**Enterprise → 1 kolom centered, beda treatment**

## 7. CONTENT NOTES UNTUK DEVELOPER

1. **Harga** — tampilkan dengan `toLocaleString('id-ID')` untuk format Rupiah yang benar
2. **Badge "Paling Populer"** — absolute positioned di top center card, z-index di atas card border
3. **Add-on "sudah include"** — kalau paket sudah include sesuatu (misal dashboard di e-commerce), jangan tampilkan add-on tersebut di accordion. Filter di data layer.
4. **CTA WhatsApp** — buka `wa.me/628561475550` dengan pesan pre-filled berisi nama paket yang dipilih
5. **Pre-filled WA message contoh:**
   ```
   Halo KyloDev, saya tertarik dengan Paket Business (Web Solution).
   Bisa bantu saya untuk info lebih lanjut?
   ```
6. **Enterprise card** — gunakan dark background (#0D0D0D) dengan teks putih dan accent lime, berbeda dari card lain
